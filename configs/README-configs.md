# TCC Ready Configurations

This directory contains configuration files for TCC (Time Coordinated Computing) ready applications. These configurations are optimized for low-latency and high-throughput performance on Intel architecture.

## Directory Structure

- `<platform>/`: Contains configurations specific to various platforms. Each subdirectory corresponds to a different platform. Examples include:
  - `baremetal/`: Contains configurations for deploying TCC applications on bare metal servers.
  - `vmware/`: Contains configurations for deploying TCC applications on VMware virtual machines.

## Usage

To use these configurations, copy the relevant files to your application directory and modify them as needed. Make sure to test your application thoroughly to ensure optimal performance.
